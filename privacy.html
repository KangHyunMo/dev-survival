개인정보처리방침

시행일: 2026년 10월 30일

1. 이 방침이 적용되는 대상

이 방침은 YouTube 채널 「개발자 생존본능」 운영에 사용하는 자체 영상 업로드 도구(이하 "도구")와 이 웹사이트에 적용됩니다. 도구는 채널 소유자 한 사람이 개인용으로 사용하며, 일반에 배포되지 않습니다.

2. 수집하는 정보

이 웹사이트는 방문자의 개인정보를 수집하지 않습니다. 쿠키, 분석 스크립트, 광고 추적을 사용하지 않습니다.

도구는 Google OAuth를 통해 채널 소유자 본인의 YouTube 계정에만 접근합니다. 접근 범위는 다음과 같습니다.

  • 영상 업로드 및 메타데이터(제목·설명·태그·공개 범위·재생목록) 관리
  • 채널과 영상의 통계·분석 데이터 조회(조회수, 시청 지속률 등)

시청자, 구독자, 댓글 작성자 등 제3자의 개인정보는 수집·저장하지 않습니다.

3. Google 사용자 데이터의 이용

Google API를 통해 얻은 데이터는 채널 소유자 본인의 영상을 올리고 성과를 확인하는 목적에만 사용합니다. 이 데이터를 제3자에게 판매·제공·공유하지 않으며, 광고 목적으로 사용하지 않습니다.

도구의 Google API 데이터 이용은 Google API 서비스 사용자 데이터 정책의 제한적 사용(Limited Use) 요건을 준수합니다.

4. 저장과 보관

OAuth 토큰과 조회한 통계는 채널 소유자의 개인 컴퓨터에만 저장되며, 외부 서버로 전송되지 않습니다. 소유자가 Google 계정 설정에서 접근 권한을 해제하면 토큰은 즉시 무효화됩니다.

5. 접근 권한 해제

Google 계정의 타사 액세스 관리 페이지에서 언제든지 권한을 해제할 수 있습니다.
